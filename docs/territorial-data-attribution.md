# Catálogo geográfico de Chile
El archivo `shared/chile-communes.json` está basado en las divisiones administrativas de [Open Admin Data — Chile](https://github.com/open-admin-data/chile-administrative-divisions), publicado bajo **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

**Adaptaciones efectuadas:** transformación al contrato `regionCode, regionName, communeCode, communeName`; corrección de la entrada Pozo Almonte (en la fuente figuraba Tocopilla para CL01401); incorporación de la comuna Antártica (CL12202), para mantener 346 comunas distribuidas en 16 regiones.

Fecha de consulta: octubre de 2026. Estos datos geográficos se utilizan exclusivamente como catálogo local de regiones y comunas y no como indicador de ofertas laborales.
