# Catálogo territorial de Chile

El selector región→comuna se deriva de los Códigos Únicos Territoriales (CUT) publicados por SUBDERE en la planilla `CUT_2018_v04.xls`, consultada el 23 de octubre de 2026. La planilla fue descargada desde el enlace expuesto por la ficha del catálogo IDE Chile/Geoportal. Como contraste, el Observatorio Logístico describe un maestro de regiones, provincias y comunas generado con información de SUBDERE y el Banco Integrado de Datos del Estado de Chile publica códigos comunales del INE.

La fuente oficial de esta versión identifica códigos y nombres territoriales, incluida la región de Ñuble. El catálogo sirve para normalizar ubicación de ofertas; no implica que todas las comunas tengan vacantes.

Referencias:

- IDE Chile, Planilla Códigos Únicos Territoriales (CUT): https://geoportal.cl/geoportal/catalog/35342/Planilla%20C%C3%B3digos%20%C3%9Anicos%20Territoriales%20%28CUT%29
- SUBDERE, archivo de códigos CUT: https://www.subdere.gov.cl/sites/default/files/documentos/CUT_2018_v04.xls
- Observatorio Logístico, maestro de comunas, provincias y regiones: https://www.observatoriologistico.cl/datos/maestro-de-comunas-provincias-y-regiones-con-su-respectivo-codigo
- BIDAT, códigos de comunas del INE: https://bidat.gob.cl/details/ficha/dato/codigos-comunas-5

La planilla CUT identificada en la ficha Geoportal se publicó en 2018. Antes de utilizar códigos para un trámite oficial, se debe contrastar la versión vigente que publique SUBDERE.
